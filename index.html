Ramping up safely
  • Start at step 1. Every two weeks, if the zoanthids open fully and the green star polyps spread out like grass, move up one step.
  • If zoanthids stay closed, shrink, or lose color, or the GSP stays pulled in, go back one step and stay there for two weeks.
  • Step 6 is the 1 W per gallon rule of thumb. GSP and most zoanthids don't need more than that, and many do well below it.
  • The light fades between the hourly points, so lights-on and lights-off are gentle ramps rather than switches.

The name, peak watts, and total and main light hours are printed above the code, so you can tell images apart in Photos. On iPhone, press and hold the code and choose Save to Photos, then import it from the Noo-Psyche app. On a computer, right-click it and save the image.

How the code is laid out 
WWBBGGUUCCRR#  then 24 ×  HHMM WW BB GG UU CC RR
└ channel limits, hex %   └ hour, minute, channel %, all hex

Plain text, byte mode, error correction H. The channel order is White, Blue, Green, UV, Cyan, Red (as the K7 Pro III uses it). If a code has a different number of channels, the editor reads the count from the limits and labels them Channel 1, 2, and so on.
