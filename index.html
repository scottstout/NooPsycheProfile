Strength step

Step 6 is your full target. Steps 1 to 5 run from 50% to 90% of it, for acclimating: a new tank, newly added corals, or corals moving from a weaker light. Corals already used to this light can go straight to step 6.

Stepping up while corals acclimate
  • Start at step 1. Every two weeks, if the corals look healthy (zoanthids open fully, green star polyps spread out like grass), move up one step.
  • If corals stay closed, shrink, or lose color, go back one step and stay there for two weeks.
  • If you set the target with the 1 W per gallon rule of thumb, note that GSP and most zoanthids don't need more than that, and many do well below it.

Match the app's watt reading

Watts here are estimated from the K7 Pro IV's 100 W rating. To make them exact, import a profile into the app, read the watts it shows at the brightest time, and enter it here. Estimates and new profiles then use that correction.

The name, peak watts, and total and main light hours are printed above the code, so you can tell images apart in Photos. On iPhone, press and hold the code and choose Save to Photos, then import it from the Noo-Psyche app. On a computer, right-click it and save the image.

How the code is laid out 
WWBBGGUUCCRR#  then 24 ×  HHMM WW BB GG UU CC RR
└ channel limits, hex %   └ hour, minute, channel %, all hex

Plain text, byte mode, error correction H. The channel order is White, Blue, Green, UV, Cyan, Red (as the K7 Pro III uses it). If a code has a different number of channels, the editor reads the count from the limits and labels them Channel 1, 2, and so on.
